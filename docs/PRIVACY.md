# 权限、数据与隐私

## 为什么需要辅助功能

点击优化后，助手读取目标应用聚焦的多行输入框，并将优化结果回填；Ctrl+Z 可按严格匹配条件转发一次原生 Cmd+Z。辅助功能具有控制其他应用的能力，只有你确认来源后才授予本助手。助手无法自行授予权限。

只接受 Codex/Claude 桌面白名单。不会扫描浏览器、终端或任意应用寻找草稿，也不后台收集聊天历史。不代表 macOS 权限本身被限制到这两款应用。

## 哪些内容离开电脑

只在显式点击优化时将当前草稿和编辑指令交给你选择的后端。Codex CLI 使用其认证；API 将请求发送到你配置的服务。具体后端/服务的数据政策和计费由你确认。

无内置公共 Key、开发者中转服务、分析埋点或后台模型轮询。不附带聊天历史、其他文件或附件。API 不跟随重定向、不自动重试。

## 本地数据

- `config.json`：本机明文 API Key 和模型配置，文件0600，不加密，不上传 GitHub。
- `runtime-status.json`：应用路径、版本、PID、辅助功能检查、操作阶段及数值；不写草稿、服务URL、Key或响应正文。
- “查看原文”：仅在进程内存，退出/升级清空。
- 原生粘贴：暂用系统剪贴板，只有剪贴板未被用户更新时恢复之前的内容。
- CLI：临时目录0700，输入/schema0600，正常完成/取消/超时清理；崩溃或强制终止可能残留临时文件。
- 本地签名：专用钥匙串及密码文件位于 Application Support 的 Signing 目录，永不提交源码/安装包。

该工具面向普通纯文本草稿；不建议用于密钥、凭据或其他不应交给模型服务的敏感内容。反馈问题只用虚构测试文本，并自行脱敏截图。
